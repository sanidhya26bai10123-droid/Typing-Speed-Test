# Typing Speed Test

A simple Python project made by a first-year CSE student to test typing speed.

## About the Project

This project is a **Typing Speed Test** made using Python and Tkinter.

The program shows a paragraph on the screen. The user clicks the **Start** button and starts typing the paragraph.

The program gives **60 seconds** to type. It automatically submits the test when the paragraph is completed or when the time is over.

At the end, it shows the typing speed in **Words Per Minute (WPM)**.

## Features

* Simple graphical interface
* Start button
* Random paragraph selection
* 60-second timer
* Automatic submission
* WPM calculation
* Beginner-friendly Python code

## How to Use

1. Open the program.
2. Click the **Start** button.
3. A random paragraph will appear.
4. Type the paragraph in the text box.
5. The 60-second timer will start.
6. The test automatically finishes when the paragraph is completed.
7. If the timer reaches zero, the test also finishes automatically.
8. Your typing speed will be displayed in WPM.

## WPM Calculation

The project uses this formula:

```text
WPM = Words Typed × 60 / Time Taken in Seconds
```
